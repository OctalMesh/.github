<h1 align="center">OctalMesh GitHub Configuration</h1>

This repository contains organization-wide GitHub configuration for the
OctalMesh organization, including standard templates, workflows, and guidelines.

It also contains the primary documentation for contribution, security, and
licensing for the organization.

> If an individual repository provides its own `CONTRIBUTING.md`, `SECURITY.md`,
> or `LICENSE.md` file, those local files take precedence over the versions in
> this repository.
